# ESP32 Embedded Systems Journey

A hands-on learning portfolio for ESP32, electronics and embedded systems.

| Project | Focus | Status |
| --- | --- | --- |
| [Project 01 — LED Status Indicator](Project-01-ESP32-LED-Status-Indicator/) | GPIO23, LED, blinking and serial messages | Physical prototype |
| [Project 02 — WiFi RSSI Scanner](Project-02-ESP32-WiFi-RSSI-Scanner/) | Wi-Fi scan, RSSI, serial records | Physical photos and records |
| [Project 03 — Analog Sensor Simulator + Python Classifier](Project-03-ESP32-Analog-Sensor-Simulator/) | Voltage divider, ADC, LED threshold, Python functions | LED and outputs shown; ADC reading requires validation |

Projects contain source code, wiring, schematics or block diagrams, parts lists and test records. The portfolio progresses toward environmental sensing and multi-node projects. Never connect a 9 V battery directly to ESP32 pins.
