# ESP32 Embedded Systems Journey

A hands-on learning portfolio for ESP32, electronics and embedded systems.

| Project | Focus | Current status |
| --- | --- | --- |
| [Project 01 — ESP32 LED Status Indicator](Project-01-ESP32-LED-Status-Indicator/) | GPIO23 output, an LED, timed blink patterns and serial messages | Physical prototype and sketch documented |
| [Project 02 — ESP32 WiFi RSSI Scanner](Project-02-ESP32-WiFi-RSSI-Scanner/) | Wi-Fi scans, strongest RSSI selection and serial records | Physical build photo and Serial Monitor screenshot included |

Each project contains source code, wiring instructions, a circuit schematic or functional block diagram, a bill of materials and an honest record of testing.

The projects progress from basic GPIO control toward sensor acquisition and environmental monitoring. Software-implemented features are distinguished from features verified on physical hardware.

**Hardware safety:** Power the ESP32 through its compatible USB input. Use a series resistor for an external LED and never connect 9 V directly to a GPIO pin.
