# Build log — 13 Nov 2026

- **Goal:** Learn ESP32 digital GPIO output with an external LED.
- **Hardware:** ESP32 USB-powered board, breadboard, blue LED, approximately 260 Ω series resistor, jumper wires.
- **Pin:** GPIO23 / D23.
- **Program:** First the simple 1-second blink, then timed normal/alert patterns over one LED plus Serial status labels.
- **Reported result:** External LED blinked correctly in the real circuit.
- **Evidence:** Photos and a demonstration video supplied by the project builder; see accompanying downloadable project archive if media are not yet on GitHub.
- **Not yet implemented:** A pushbutton input, sensor data, automatic hazard detection, or network telemetry.
- **Next milestone:** Learn digital inputs and event-triggered alerts, then sensor readings.

The demo video may show a power indicator LED on the ESP32 itself; that LED is separate from the external blue LED that the program controls.
